# AGENTS.md

Guidance for AI coding agents working in the **ArturSepp** repository.

## Python environment

- Keep this repository's Python environment outside OneDrive at `C:\Python\ArturSepp312`.
- Never create, use, or install packages into a repository-local `.venv`.
- Use `C:\Python\ArturSepp312\Scripts\python.exe` for all Python commands.
- Run tools through that interpreter, for example `C:\Python\ArturSepp312\Scripts\python.exe -m pytest` and `C:\Python\ArturSepp312\Scripts\python.exe -m pip`.
- If the environment is missing, create it with `py -3.12 -m venv C:\Python\ArturSepp312`; do not create `.venv` under the repository.
